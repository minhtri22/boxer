# Glossary

## A1
P1-A1 — Step → Straight Reach. Advancing/neutral/retreating straight reach factors 1.06 / 1.00 / 0.94.

## A2
P1-A2 — Punch Gesture Vocabulary. Right-thumb gesture selects punch family.

## A3.1
P1-A3.1 — Hook Close-Range Coupling. Full hook forward effectiveness through 1.05m, falloff to 0.86 by 1.25m.

## A3.2
Uppercut body-coupling experiment. LOCKED / not started.

## A3.3
Overhand body-coupling experiment. LOCKED / not started.

## B1
Opponent finite reach / locked target / no homing during committed punch.

## B1.5
Arm embodiment/readability series covering explicit elbow topology, shoulder anchoring, glove coherence, upper-arm readability, guard naturalization and visual cleanup.

## B2
Opponent pelvis + lower-body embodiment.

## Authoritative Combat
State and geometry used to decide combat outcome.

## Presentation Layer
Rendered body/animation/debug/visual cues. Must not silently redefine combat authority.

## Combat Endpoint
Authoritative geometric punch target/path endpoint used by combat resolution.

## Visual Glove
Rendered end effector of the arm chain; may be distinct from hidden combat geometry.

## Punch Family
Straight, Hook, Uppercut, Overhand.

## Punch Intent
Specific contextual attack intent including family/hand semantics.

## Commit
Attack phase where intent/target is committed and telegraphed before extension/resolution.

## Extend
Attack phase where punch moves toward target.

## Recover
Attack phase returning from extension toward stance/guard.

## Human PASS
Verified by actual user UAT on real device for the specific acceptance question.

## Implementation PASS
Source behavior/test gate satisfied; does not imply human acceptance.

## Web Surrogate
WebGL/HTTPS/iPhone Safari route used to validate interaction/readability. Not proof of native iOS performance.

## Body Embodiment
Visual representation connecting combat state to readable anatomy/body segments.

## Semantic Event
Structured record of meaningful combat state/action suitable for evidence, analysis and future replay.

## Provenance-Locked Build
Build produced from committed clean source where source short SHA = build marker = productVersion = metadata build_commit.
